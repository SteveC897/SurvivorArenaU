# 《吸血鬼幸存者》局外成长系统拆解

> 结论先行：VS 的局外成长不是"数值堆叠"，而是**一套用局内表现当货币、逐层揭示新系统的解锁流水线**。
> 金币买的是"容错率"，真正被解锁的是"玩法维度"。

---

## 一、先分层：局内循环 vs 局外成长

| 层 | 内容 | 是否跨局保留 |
|---|---|---|
| 局内成长 | 拾取经验 → 升级三选一 → 武器/被动等级 → 宝箱进化 → 21:00 后数值爆炸 | 否 |
| **局外成长（本文对象）** | 金币 PowerUps、角色、武器/被动入池、关卡、收藏、遗物、秘法牌、模式开关、隐藏内容 | **是** |

关键点：VS 的局外成长里，**只有第一项是纯数值**，其余六项都是"往游戏里加东西"。这是它和传统 roguelite（以永久属性加成做主线）最本质的区别。

---

## 二、六层系统与解锁条件

### L1 金币 / PowerUps —— 唯一的数值型局外成长

- 局内掉落金币，局外花金币在 PowerUp Selection 买永久属性，对所有角色生效。
- 共 27 项：Might / Armor / Max Health / Recovery / Cooldown / Area / Speed / Duration / Amount / Move Speed / Magnet / Luck / Growth / Greed / Curse / Revival / Omni / Charm / Defang / Reroll / Skip / Banish / Preserve / Seal 系列。
- **价格公式**（这条最重要）：

  ```
  单级价格 = 初始价 × (1 + 已购该强化级数) + ⌊20 × 1.1^已购总级数⌋
  ```

  - 第一项：同一强化每买一级，基础价往上加一个初始价（线性）。
  - 第二项：**只要买过任何强化，每一级都附加一笔随"总购买级数"指数增长的"手续费"**。
  - 初始价跨度极大：Might 200 → Armor 600 → Cooldown 900 → Curse 1666 → Amount 5,000 → Revival / Charm / Seal 各 10,000。
  - 全部买满总价约 **27,148,513 金币**，其中 90% 是手续费。
- **可全额退款**（Refund PowerUps），退款无损耗。

### L2 角色

| 获取方式 | 例子 |
|---|---|
| 成就（达成某种局内行为） | 任意角色存活 10 分钟 → Peachone 相关；单局赚 5000 金 → Dommario；累计击杀 3000 骷髅 → Mortaccio；累计 100,000 击杀 → Krochi |
| 关卡内棺材（Coffin） | Mad Forest→Pugnala、Inlaid Library→Giovanna、Dairy Plant→Poppea、Gallo Tower→Concetta、Cappella Magna→Zi'Assunta |
| 收集度 | 集齐 1.0 全部收藏 → Queen Sigma |

- 角色不只是"另一种手感"：**很多武器只有用对应角色开过局，才会进入升级三选一的公共池**。所以角色解锁 = 武器池扩容。

### L3 武器 / 被动入池

- 通过成就解锁，条件是三类"证明你会用"的动作：
  - 等级门槛：King Bible 4 级 → Bracer；Magic Wand 7 级 → Duplicator；Pentagram 7 级 → Christine
  - 存活门槛：用 Pasqualina 存活 5 分钟 → Runetracer；任意角色 20 分钟 → Pentagram
  - 行为门槛：摧毁 20 个光源 → Fire Wand；捡到 5 个地板鸡 → Garlic；捡到 Vacuum → Attractorb
  - 构筑门槛：同时持有 6 把不同武器 → Empty Tome；同时持有 6 个进化 → Torrona's Box

### L4 关卡（主线推进的主干）

纯等级门槛，且**是"在上一张图里达到某等级"**，与存活时长无关：

```
Mad Forest ──等级20──▶ Inlaid Library ──等级40──▶ Dairy Plant
   ──等级60──▶ Gallo Tower ──等级80──▶ Cappella Magna
```

- 等级门槛本身就隐含了"存活时长 + 拾取效率 + 输出效率"，但玩家看到的目标是"练到 20 级"，而不是"活 15 分钟"——**心理压力完全不同**。
- 支线/特殊关卡另开一套（Hyper 模式解锁数量、Boss 击杀等）：Il Molise、Moongolow、Green Acres、The Bone Zone、Boss Rash。
- 每张主线图再叠三种难度层：**Hyper**（击杀该图 Boss 解锁）→ **Inverse**（Gracia's Mirror）→ **Endless**（Seventh Trumpet）。

### L5 遗物（Relic）——真正意义上的"系统解锁钥匙"

遗物不提供数值，它提供**功能**。这是 VS 局外成长的核心设计。

| 类别 | 遗物 | 作用 |
|---|---|---|
| 信息可读化 | Grim Grimoire | 暂停菜单查看"已发现的进化配方" |
| | Ars Gouda / Milky Way Map | 图鉴 / 暂停菜单地图 |
| | Mindbender | 角色外观、**最大武器槽数量**、收藏夹 |
| 体验调节 | Sorceress' Tears | Hurry 模式（全局加速） |
| | Roast Chicken with a Clock | 战斗中随时加速按钮 |
| | Magic Banger | 更换 BGM |
| | Trisection / Brave Story | 随机事件 / 随机升级（自己给自己加随机性） |
| 内容钥匙 | **Randomazzo** | **开启整个秘法牌（Arcana）系统** |
| | **Yellow Sign** | 揭示隐藏道具（银戒/金戒/Metaglio 系列）与隐藏事件 |
| | Glass Vizard | 让商人在所有关卡出现 |
| | **Great Gospel** | **Limit Break**（武器突破等级上限） |
| | Atlas Gate | 解锁 Adventures（独立小剧本） |
| | Forbidden Scrolls of Morbane | 开启 Secrets 菜单与咒语输入 |
| | Apoplexy / Antidote / Wax Fetish | 解锁 Charm / Defang / Preserve 三项 PowerUp |
| 终局 | Eudaimonia Machine | 需集齐全部标准遗物才开放 → 产出 Gracia's Mirror / Seventh Trumpet |

- 遗物的获取方式高度统一：**在地图某个方位，绿色箭头指引，走过去捡起来**。也就是"探索型解锁"。

### L6 秘法牌（Arcana）——全局修正卡

- 前置：找到 Randomazzo（Gallo Tower），同时解锁 VI - Sarabande of Healing。
- 其余 21 张基础秘法牌的两条解锁线：
  - **用某角色达到等级 50**（大多数：Antonio、Imelda、Pasqualina、Gennaro、Arca、Porta、Poe、Christine、Krochi、Giovanna、Dommario、Concetta、Poppea、Lama、Suor Clerici…）
  - **在某张图撑到 31:00**（即击败 30:00 出现的死神 The Reaper，或坚持过 31 分）：Mad Forest→VIII、Gallo Tower→XII、Inlaid Library→XV、Dairy Plant→XX
  - 另有 Game Killer (0)：在 Cappella Magna 击败最终敌人
- 局内机制：开局自选 1 张 → 11:00 / 21:00 的秘法牌 Boss 掉宝箱 → 再选 1 张（共 3 张；解锁 23 张以上后宝箱给 6 选 1 并附赠 1 次 Reroll）；Inverse 模式下商人 20,000 金卖一张。
- 也就是说：**秘法牌的解锁是"端到端通关证明"**——把角色练到 50 级或把图打穿 31 分钟，难度远高于解锁一张地图。

### L7 游戏模式与隐藏层

| 模式 | 钥匙 | 隐藏了什么 |
|---|---|---|
| Hurry | Sorceress' Tears | 全局加速 |
| Hyper | 各图 Boss | 高难版本 |
| Inverse | Gracia's Mirror | 全图反转 + 商人卖秘法牌 |
| Endless | Seventh Trumpet | 关闭死神、无限循环 |
| Limit Break | Great Gospel | 武器超过满级继续成长 |
| Adventures | Atlas Gate | 完全独立的剧本模式 |
| Darkanas | Darkasso（Room 1665） | 第二套秘法牌，条件更苛刻（特定角色的特定任务） |
| Secrets / Spells | Forbidden Scrolls | 秘密角色 + 作弊码 |

## 三、推进节奏：一个玩家的实际解锁顺序

用"系统数量"而不是"内容数量"来看，节奏是这样的：

| 阶段 | 时长感 | 玩家已解锁的系统 | 每局目标 |
|---|---|---|---|
| **前期** | 第 1–5 局 | 金币 PowerUps、升级三选一、1 张图、1 个角色 | 活更久、拿更多金币 |
| **展开期** | 第 5–20 局 | 3 张图、多个角色、武器池快速扩容、收藏菜单 | 达到等级门槛解锁下一张图 + 顺手捡棺材 |
| **探索期** | 第 20–50 局 | 遗物（地图/图鉴/音乐/加速）、Hyper、商人、进化配方可视化 | 按绿色箭头跑图、开棺材、拿遗物 |
| **深水区** | 第 50–120 局 | **秘法牌、Reroll/Skip/Banish/Seal、Limit Break、Inverse、Endless** | 把角色练到 50 级刷秘法牌；挑战 31 分钟 |
| **终局** | 120 局+ | Eudaimonia Machine、Adventures、Darkanas、Secrets/Spells、全收集 | 完成度收尾 + 自设挑战 |

三条主线的相互牵制（这是节奏感的来源）：

```
金币 ──▶ PowerUp 强度 ──▶ 能活更久 / 练更高等级 ──▶ 解锁新图、秘法牌
  ▲                                                        │
  └──────────── 新图 = 更多金币产出、更多遗物 ◀─────────────┘
```

任何一条线单推都会撞墙：只刷金币不推图 → 金币效率低；只推图不买强化 → 等级门槛够不到；只练级不探索 → 永远拿不到遗物和秘法牌。

## 四、解锁条件的"类型学"

把上面所有条件抽象一下，会发现 VS 刻意用了五种完全不同的触发器，覆盖五种玩家动机：

| 触发器类型 | 例子 | 服务的玩家动机 |
|---|---|---|
| **阈值型**（等级/分钟） | 等级 20/40/60/80 解锁地图；31:00 解锁秘法牌 | 目标明确、可预期，给"下一次就成"的驱动力 |
| **累计型**（跨局计数器） | 累计击杀 3000 / 100,000；单局 5000 金 | 让"失败的局"也有产出，降低挫败 |
| **探索型**（地图空间） | 棺材、遗物、Yellow Sign 后的隐藏道具 | 奖励好奇心与地图熟悉度 |
| **构筑型**（局内 build） | 某武器到 4/7 级；同时持有 6 把武器/6 个进化 | 教学：逼玩家理解合成与进化系统 |
| **完成度型**（元进度） | 收藏 50/60/…/100 格 → Mindbender、Banish；集齐遗物 → Eudaimonia | 给"收集控"一条独立且确定的长线 |

**注意隐藏机制**：在找到 Randomazzo 之前，"秘法牌"相关的成就条目根本不显示。这既是防信息过载，也是刻意的"啊，原来还有这种东西"的惊喜设计——新系统的存在本身就是奖励。

## 五、金币经济的设计细节

1. **低价起步 + 高频正反馈**：Might / Max Health / Recovery / Greed 都是 200 金币起，前几局就能买。玩家的第一笔消费永远买得起。
2. **线性基础价 + 指数手续费**：基础价按"该项已购级数"线性涨，手续费按"总购买级数"指数涨（20 × 1.1^总级数）。
   - 结果是**鼓励"广度优先"而非"深度优先"**：先买 27 项各 1 级，比把 Might 堆到 5 级便宜得多。
   - 广度优先让玩家体验到更多属性维度 → 每局 build 感受差异更大 → 而不是纯数值膨胀。
3. **单级上限很低**：Might 5 级 +25%、Armor 3 级 +3、Area 2 级 +10%。**局外数值天花板被刻意压低**，强度主要来自局内 build 与操作。
4. **顶级项 5,000 / 10,000 金币起**：Amount（+1 投射物）、Revival（复活一次）、Charm、Seal —— 这些是"改变质感"的门槛项，被定价成中期目标。
5. **免费退款**：反复试错零成本。这是对"加点焦虑"的直接消解，也鼓励玩家针对不同角色/关卡重新配点。
6. **Curse 是可以买的负面属性**：花 1,666 金币起买"敌人更多更强"。把"自虐难度"做成付费商品，是 VS 对硬核玩家的服务方式。
7. **Greed（+50% 金币）与 Charm / Defang / Seal 分别由遗物解锁**——即"经济加速器"本身也是可解锁内容。

## 六、设计目的：这套解锁方式在解决什么问题

### 1. 让"失败"也有产出，把死亡从惩罚变成进度
VS 几乎没有"局内惩罚"：金币、击杀数、成就进度全部跨局保留。一局死在 12 分钟，仍然推进了三四个累计型解锁。
对一个"每局都会死"的游戏类型，这是把负反馈转化为正反馈的最廉价手段。

### 2. 局外只给容错率，不给答案
最大化的 PowerUps 也只提供约 +25% 伤害、+3 护甲、+10% 范围……而一局真正的强度来自：武器选择与进化的理解、走位、拾取路线、对 Boss 时间轴的记忆。
**设计目的是保住"技巧仍然是主导变量"**，避免出现"刷够了就无敌"（那会让后期的所有挑战失去意义）。

### 3. 解锁是"软教程"，用目标代替说明
想解锁 Inlaid Library？先练到 20 级 → 你自然学会了收集经验、保持存活、控制输出。
想解锁 Arcana？把某角色练到 50 级 → 你自然学会了 build 与进化。
想拿 31:00 的秘法牌？你必须学会应对死神。
**每一条解锁条件都在教你下一阶段需要的技能，且从不说教。**

### 4. 用"等级"而不是"存活时长"当门槛，是心理设计
等级门槛的隐含要求包括存活、拾取范围、清怪效率、经验加成——比"活 15 分钟"更综合，但呈现给玩家的目标更中立、更可控（Greed/Growth/Attractorb 都能帮上忙），也让"我差一点"变成"我再来一局就能到"。

### 5. 逐层揭示，对抗内容过载
VS 首局只有：移动、武器自动开火、升级三选一。秘法牌、Limit Break、Inverse、Endless、Adventures 全部藏在几十小时的流程之后，且**在解锁前连 UI 条目都不出现**。
结果是：新玩家永远只面对 3–4 个待办目标，而老玩家时刻能挖到"居然还有一层"。
**总内容量极大，但任一时刻的认知负荷恒定。**

### 6. 遗物：把"功能性"也变成奖励
大多数游戏把地图、图鉴、BGM 选择、加速功能当"设置项"默认开放。VS 把它们做成需要在地图上跑过去捡的遗物。
这样做的收益是多重的：
- 每一个"非数值奖励"都变成一次探索目标，中期的重复刷图不再空洞；
- 捡到的功能立刻改善体验，形成即时正反馈；
- 由于遗物需要走遍地图，玩家被迫熟悉地形与隐藏路线，为后期 Inverse 模式提前做了地图教学。

### 7. 三条独立的长线同时并行，服务不同动机
- **数值控**：金币 → PowerUps（几乎无限的金币池）
- **收藏控**：收藏菜单 → Mindbender / Banish / Queen Sigma（完成度型）
- **挑战控**：31:00 死神、Inverse、Endless、Limit Break、Curse 自虐（技巧型）
三套动机互不干扰，玩家可以只玩其中一条，也可以全都要。

### 8. 大量"自我施加随机性"的解锁，延长寿命
Trisection（随机事件）、Brave Story（随机升级选项）、Random LevelUp、Curse、Party Mode、Seal（主动屏蔽掉落池）——**把"再玩一遍"的动机从"拿奖励"转成"换个规则玩"**。
当一个玩家开始主动封印自己常用的武器、给自己加随机性时，他其实已经完成了从"通关者"到"自设目标者"的转变，这是这类游戏寿命的真正上限。

### 9. 单局与局外的价值互相锚定
- 局外解锁的内容，几乎全部是"改变下一局怎么玩"（新武器、新秘法牌、新角色、新模式），而不是"减少下一局的难度"。
- 反过来，局内表现（等级、分钟数、击杀数、金币）直接充当解锁货币。
**两个循环互为对方的燃料，而不是两个并行的进度条。**

## 七、代价与边界（这套设计的副作用）

- **前期信息饥饿**：首 1–2 小时内容极薄，只有一张图一个角色，靠"再来一局"的快感撑住；对需要明确目标的玩家不够友好。
- **中期目标拥挤**：约 10–30 小时之间，同时有金币、角色、棺材、遗物、秘法牌、模式共 6–7 条待办线，容易出现"不知道该干嘛"的失焦感（社区里大量的"解放顺序推荐"攻略就是这个问题的产物）。
- **收集度依赖**：Banish / Seal / Reroll 等重要的构筑自由度被锁在收藏度与角色 80 级之后，前期玩家的 build 控制力明显偏弱。
- **长尾价格失衡**：全部买满 2,700 万金币，其中 90% 是手续费——后期纯粹是"金币回收站"，其功能是维持 Endless / Gold Fever 这类刷金币玩法的意义，而不是真的还会被买满。

## 八、可迁移的设计清单（如果要做同类系统）

1. 局外只加"容错率"，不加"答案"；数值上限压制在 20–30% 量级。
2. 用一种局内产出（这里是金币）当唯一货币，且允许免费重置。
3. 价格设计成"广度优先比深度优先便宜"，引导体验多样性而非数值膨胀。
4. 解锁条件至少覆盖 3 种触发器类型（阈值 / 累计 / 探索），以服务不同动机的玩家。
5. 隐藏系统的**存在本身**：在揭示前不显示条目，用"发现"给第二次惊喜。
6. 把地图、图鉴、音乐、加速这类"功能"做成可探索的奖励，而不是默认设置。
7. 让每条解锁条件都在教授下一阶段所需的技能。
8. 保证"失败的局"也至少推进 1–2 个跨局计数器。
9. 提供"自加难度 / 自加随机性"的可购买或可解锁选项，给硬核玩家出口。
10. 保留一个 30 小时之后才开放、且需要集齐前置才能进入的终局房间（如 Eudaimonia Machine），把所有长线收束到一个明确的"你完成了"节点。
