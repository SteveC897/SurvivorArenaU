# 01 · 战斗场景（伊梅尔达 / 疯狂森林 5 分钟）

> 当前场景已经从「光环测试」升级为可玩的局内循环：
> **强能魔杖开局 → 击杀蝙蝠 → 掉经验宝石 → 拾取升级 → 三选一 → 武器/被动成长 → 宝箱 Boss → 5:00 胜利**。
> 武器/被动数值来源见 [03-局内成长-武器-宝箱.md](03-局内成长-武器-宝箱.md)；
> 属性管线见 [02-属性修改器管线.md](02-属性修改器管线.md)。

---

## 一、运行方式

1. Unity 2022.3.62f3c1 打开项目，打开 `Assets/Scenes/MainGame.unity`，直接 Play。
2. 操作：`WASD` / 方向键移动；升级时**鼠标点击卡片**或按 `1` / `2` / `3`；胜利后按 `R` 重开。
3. 场景由代码生成：
   `Tools → Survivor Arena → Rebuild Test Battle Scene`。
4. 打 Windows 包：
   `Tools → Survivor Arena → Build Windows Test Player`，
   输出到 `%TEMP%/SurvivorArenaTestBuild/SurvivorArenaU.exe`。

## 二、本场景规则

| 项 | 规则 |
| --- | --- |
| 单局时长 | **5:00（300 秒）** |
| 波次 | 30 波，每 10 秒一波，开波时间 0:00–4:50 |
| 敌人 | 只有蝙蝠；从主角周围 **8–10 单位**生成，直线追踪 |
| 敌人血量 | 普通蝙蝠 **5**；宝箱蝙蝠 120 / 240 / 360 |
| 刷怪 | 当前波次的「数量下限 + 补刷间隔」；达到下限停止补刷 |
| 离屏回收 | 主角跑远时，超过约 16 单位的普通蝙蝠移到相机边缘外；**只改位置，不击杀/不消失**；Boss 不参与回收 |
| 主角 | 可八向移动；**当前没有生命值/受伤/死亡流程**，不会被蝙蝠撞死 |
| 初始武器 | **强能魔杖（Magic Wand）**，锁定最近敌人发射魔法弹 |
| 武器/被动槽 | 各 **6** 格；开局只占 1 个武器槽（强能魔杖） |
| 经验 | 击杀掉经验宝石；走近吸附并拾取；宝石上限 256，超出淘汰最早的一颗 |
| 升级 | 经验满后暂停 Gameplay，弹出 **3 选 1**；武器 8 级、被动 5 级（双鸾宝镯 2 级） |
| 宝箱 | 1:00 / 2:30 / 4:30 出现宝箱蝙蝠；击杀后掉宝箱，走上去开；奖励位 **1 / 3 / 5** |
| 结束 | 5:00 停止刷怪、清场、弹出「胜利！」；`R` 重开 |

### 本场景明确不做

- 武器进化/超武（M9）：配方与进化武器暂缓；
- 秘法牌（M10）：整套暂缓；
- 跳过/重选/排除：按 `00-profile` 暂缓；
- 玩家受伤、死亡、复活：当前没有；
- 场景外主菜单/角色选择/收藏：全部不做。

## 五、分层架构

### 5.1 层职责

| 层 | 新增/关键类 |
| --- | --- |
| **Data** | `BattleConfig`、`ContentCatalog`、`WeaponDefinition`、`WeaponLevelStats`、`PassiveDefinition`、`WaveTable` |
| **Core** | `GameClock`、`EventBus<T>`、`ObjectPool<T>`、`GamePause`、`IPlayerInput`、`IWorldViewport`、`Stats` |
| **Gameplay** | `PlayerStats`、`Loadout`、`ExperienceSystem`、`UpgradeSystem`、`WeaponSystem`、`ProjectileSystem`、`AreaEffectSystem`、`OrbitEffectSystem`、`PickupSystem`、`ChestSystem`、`EnemySpawner`、`BattleSession` |
| **Platform** | `LegacyPlayerInput` |
| **Presentation** | `BattleHud`、`LevelUpView`、`CombatPresenter`、`PlayerSpriteView`、`CameraFollow`、`InfiniteGround` |
| **Bootstrap** | `BattleBootstrap` |

依赖方向由 asmdef 固定：

```
Data        Core
  ↑           ↑
  └─ Gameplay ┘
        ↑
  Presentation        Platform → Core
        ↑
     Bootstrap → 以上全部
     Editor    → 以上全部（仅 Editor）
```

- Gameplay 不引用 Presentation；HUD/升级界面只订阅 `EventBus`；
- 武器/被动数值从 `ContentCatalog` 读；伤害/冷却/范围/数量走 `Stats`；
- 弹体/区域/环绕/宝石/宝箱都是**纯数据**，由 `CombatPresenter` 统一画；
- 升级暂停由 `GamePause` + `UpgradeSystem.IsChoosing` 控制，不改 `Time.timeScale`。

### 5.2 运行时链路

```
ContentCatalog + BattleConfig
            │
            ▼
  Bootstrap.BattleBootstrap（组合根）
    ├─ PlayerStats / Loadout（初始强能魔杖）
    ├─ ExperienceSystem + UpgradeSystem
    ├─ EnemySpawner → 普通蝙蝠 / 宝箱蝙蝠
    ├─ WeaponSystem → Projectile / Area / Orbit
    ├─ PickupSystem（经验宝石）
    ├─ ChestSystem（Boss 排期 / 宝箱 / 奖励）
    └─ BattleSession（计时 / 波次 / 胜利）
            │ EventBus
            ▼
  BattleHud（经验/等级/槽位/提示/胜利）
  LevelUpView（升级三选一）
  CombatPresenter（弹体/区域/宝石/宝箱）
```

## 七、已知限制

1. **没有玩家生命/受伤**：因此护盔、空虚之心、愈伤番茄三件防御被动只保留定义，`Offered=false`，不进入三选一；后续接玩家受伤后再打开。
2. **没有超武进化/秘法牌/跳过/重选/排除**：按 `00-profile` 暂缓；宝箱当前只给普通武器/被动升级。
3. **武器机制做了简化**：暴击、击退、飞刀间隔、圣经逐本书独立命中、圣水随机落点细节等未完全按原作；数值按文档首批实现表。
4. **宝箱时机按 5 分钟压缩**：60/150/270 秒，奖励位 1/3/5；原作是 Boss 掉落的 1/3/5 位宝箱，本场景用宝箱蝙蝠代替。
5. **只有 5 分钟/30 波**：不是原作 30 分钟；20/40 级的经验节流阀在 5 分钟局内基本不会触发。
6. **表现层**：HUD 仍用系统字体（无 TMP 中文资源）；地面只有一张 32×32 草地图块；Boss 是放大染色的蝙蝠，宝箱/区域圈是运行时生成图形。
7. **没有属性面板/暂停菜单**：当前 HUD 显示经验、等级、6+6 槽位；属性明细、ESC 暂停（`00-profile` 待办）未接。
