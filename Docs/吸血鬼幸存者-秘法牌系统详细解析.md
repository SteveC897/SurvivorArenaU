# 《吸血鬼幸存者》秘法牌（Arcana）系统详细解析

> **术语约定（全文统一）**：游戏简中把 **Arcana** 译作「**秘法牌**」（英文 wiki 的 Arcana / Arcanas），第二套 **Darkana / Darkanas** 在本文中统一写作「**暗·秘法牌**」。全文不使用其他俗称。
>
> 结论先行：秘法牌不是"更强的强化"或"第四种装备"，而是一层**改写全局规则的 Mod 层**。
> 它不占道具栏、不参与进化、不影响掉落池；它做的事情是修改已有武器与属性的**运算方式**（改公式、加区段、加触发器、换资源）。也正因如此，它是 VS 里唯一能**把既有 build 重新定义**的系统。

---

## 一、系统速览

| 项目 | 内容 |
| --- | --- |
| 一局内可获得数量 | 基础 **3 张**（开局 1 张 + 11:00 与 21:00 的秘法牌宝箱各 1 张） |
| 单局理论上限 | **无硬上限**（Queen Sigma 五档、Inverse 商人、Moonlight Bolero 宝箱等途径可继续叠加） |
| 是否占道具/武器栏 | **不占**。秘法牌是完全独立的第三条成长层 |
| 可选范围 | 开局可任选**已解锁**的秘法牌或暗·秘法牌（也可选"随机"）；若一张都没解锁，开局**不会弹出选卡界面** |
| 宝箱给牌 | 从**未收集**的秘法牌中随机给 **4 张**候选，四选一；已解锁总数（秘法牌 + 暗·秘法牌）**≥23 张**时改为 **6 张**候选，并附赠 **1 次免费 Reroll** |
| 重复获取 | 宝箱只从"未收集"里抽，因此**不会重复**；被 Reroll 刷掉的选项会**从该宝箱的池中移除**，同一宝箱内不再出现 |
| 关闭方式 | 关卡选择界面可整体关闭秘法牌；关闭后秘法牌 Boss 不再出现 |
| 系统解锁钥匙 | 遗物 **Randomazzo**（Gallo Tower 正北方）——同时永久解锁系统并直接赠送 **VI - Sarabande of Healing** |
| 扩展包解锁钥匙 | 遗物 **Darkasso**（Room 1665 最深处，累计击杀 1665 只后自动拾取）——解锁整套 **Darkanas**（暗·秘法牌），并赠送 **VI - Moonlight Bolero** |

三条关键规则（容易被记错，spec 里要写死）：

1. **持有 ≥3 张后，11:00 / 21:00 的秘法牌 Boss 只会掉普通宝箱**（不再给秘法牌）。
2. **时间轴不是绝对的**：在时限不是 30:00 的关卡里秘法牌 Boss 出现时间会变；Boss Rash / Bat Country / Tiny Bridge 三张图是 **5:00 与 10:00**（另有来源给出 Carlo Cart 5:00 / 10:00、Whiteout 7:00 / 14:00，见第五节）。携带宝箱的 Boss 是 **Pipeestrello 4（Glowing Bat）**；Whiteout 用 **Pipeestrello 5（Silver Bat）**。
3. **部分角色自带秘法牌效果，且不占槽位、不受"关闭秘法牌"影响**。例如 Avatar Infernas 自带 XIX - Heart of Fire、Nathan Graves 自带 IV - Awake、Blackmore 自带 V - Chaos in the Dark Night、Julia Laforeze 自带 VI - Sarabande of Healing 等。

## 二、获取流程图

```
                     ┌─ 若关卡选择界面关闭了秘法牌 → 秘法牌 Boss 不出现，本局无秘法牌
                     │
开局（时间轴 0:00）──┼─ 从【已解锁的全部秘法牌 + 暗·秘法牌】中**任选一张**（也可选"随机"）
                     │      · 这是玩家唯一的"点菜"机会；注意这不是"三选一"，而是"全卡池选一"
                     │      · Room 1665 例外：该关开局没有选卡界面
                     │
11:00（或 5:00 / 依关卡而定）── 秘法牌 Boss 出现 → 击杀掉落【秘法牌宝箱】
                     │      · 持有 <3 张：给候选池 = 未持有的秘法牌，随机 4 张
                     │      · 已解锁 ≥23 张：改为随机 6 张 + 1 次免费 Reroll
                     │      · 可用 Reroll 刷新（不会重复给出已出现过的选项）
                     │      · 持有 ≥3 张：只掉普通宝箱
21:00 ───────────────┘      同上，第二张
                     │
局内额外途径（叠到 3 张以上）：
  · Queen Sigma：1/2/3/77/108 级各可再选 1 张，且候选为"全部已解锁"
  · Inverse 模式：商人以 20,000 金币出售 1 张（不占张数限制；Endless 下每 30 分钟复活一次可重复购买，直到收集完所有已解锁秘法牌）
  · VI - Moonlight Bolero（暗·秘法牌）：它刷出的 Boss 掉的宝箱有几率内含秘法牌，直到收集完所有已解锁秘法牌
  · Nameless Fool（角色）：处于 Last Breath（濒死）时随机获得 1 张暗·秘法牌，单局最多 3 张
      · 各暗·秘法牌等权重，唯一例外：0 - Stake to Your Heart 只有 1% 且不受 Luck 影响
      · 常规要求当前秘法牌数未达上限（3），但用掉一次 Revival 或获得/升级 Velvet Dodecahedron 可无视该上限
```

### 22 张的机制分类（按触发器类型）

| 类型 | 代表卡 | 实现含义 |

## 四、设计解剖：秘法牌在解决什么问题

### 1. 它给"已有的 build"换了一套运算方式，而不是加一件装备
武器系统解决"我打什么"，被动道具解决"我的数值是多少"，秘法牌解决的是**"这些数值之间怎么相互作用"**。同一把 Garlic，在 Divine Bloodline 下变成护甲的输出通道，在 Blood Astronomia 下变成铺地伤害区，在 Sarabande 下变成回血武器——**同一件东西被三种规则重新定义**。这是 22 张卡能撑起数百小时的真正原因。

### 2. 构筑自由度的"第三层"，且不与其他层抢位置
武器栏、道具栏都有硬上限（并随 Mindbender 等遗物扩展），秘法牌**不占任何栏位**。这让"再强一点"的诉求有了一个不会挤压既有构筑的出口：你不需要为了变强而放弃一把武器。从系统设计角度，这是把"成长曲线"和"构筑容量"解耦的经典手法。

### 3. 用"池子稀释"做难度曲线，而不是用数值
- 宝箱给 4 选 1；当解锁总数 **≥23** 时改为 **6 选 1 并附赠 1 次免费 Reroll**。
- 这两条连在一起看，是一个**自我平衡机制**：
  - 卡池越大 → 抽到想要的那张的概率越低（稀释）；
  - 但系统同时把候选数从 4 提到 6 并送一次 Reroll（补偿）。
- 结果是：**收集得越多，单局构筑越可控**。老玩家不会因为卡池变大而失去构筑能力，新手也不会被"22 张怎么选"淹没。

### 4. 卡与卡之间刻意留出"组合爆炸"
- **IX Divine Bloodline × 反击型武器（如 Legionnaire 的分身、Mazo Familiar）**：分身击杀 = 反击击杀 → +0.5 最大生命 → 武器本身按最大生命加成伤害 → 下次更强。这是一个**自反馈循环**。
- **XV Disco of Gold × VI Sarabande of Healing**：金币治疗 → 治疗翻倍并转化为伤害脉冲 → 更多击杀 → 更多金币。
- **XIX Heart of Fire × 多弹丸武器**（Phiera Der Tuphello 等）：每个弹丸都能触发爆炸，命中数直接变成 AOE 数量。
- **VI Sarabande × 高回复**：把"回复量"整条属性从生存转为输出。
VS 没有压制这些循环，反而**保留并围绕它们设计关卡与难度**——这是"爽感来自玩家自己发现的组合"的设计取向。

### 5. 它允许"负面卡"和"玩法改写卡"存在
- **0 Game Killer** 直接**停掉经验**，把经验宝石改造成爆炸物，用"升级成长"换"宝箱收益"。这是一张**主动放弃主流成长线**的卡。
- **V Chaos in the Dark Night / XVIII Boogaloo of Illusions** 是**震荡型**：平均值中性，但方差极大——它们**不提高期望强度，只改变操作节奏**。
- **XX Silent Old Sanctuary** 奖励"空着武器栏"，等于鼓励一种反直觉的极简 build。
这类卡的存在说明设计者把秘法牌当作**"可选的规则 Mod"**而不是**"必选的升级"**，这也是它没有变成"数值通胀工具"的原因。

### 6. 获取节奏本身是节奏设计
| 时间点 | 玩家在做什么 | 秘法牌在此刻的作用 |
| --- | --- | --- |
| 0:00 | 开局，只有一个主武器 | 玩家的**唯一一次完全自主选择**，也是唯一一次能做"长线规划"的时刻（选 XX 就得空着栏位，选 X 就得围绕主武器） |
| 11:00 | build 大体成型，压力开始上升 | 第二张秘法牌作为"中期转折"，把已成型的 build 推向某个方向 |
| 21:00 | 已进入数值爆炸阶段 | 第三张是"收尾强化/娱乐化"，允许出现破坏平衡的组合 |
| 31:00+ | 死神与 Endless | Inverse 商人 20,000 金币一张，把"金币"这条经济线接到秘法牌上 |

这三张卡的位置和 VS 的其他节奏点（宝箱进化、11:00/21:00、30:00 死神）是**对齐的**：每次秘法牌到手，恰好是玩家需要重新思考"我这局要怎么打"的时刻。

## 五、容易被忽略的规则细节（复刻时必须写进 spec）

1. **秘法牌 Boss 在"秘法牌被关闭"时不出现**——这不是"不掉宝箱"，是整只 Boss 不存在，会连带影响时间轴上的压力曲线。
2. **自带秘法牌的角色**：部分角色的自带效果是"秘法牌效果"但不占槽位，也不受关闭开关影响；且**不会**因"已持有 3 张"而失效。
3. **卡面 0 号的特殊性**：Game Killer 的 0 号与塔罗"愚者"对应，游戏内也用它承担"跳出常规成长"的语义。
4. **秘法牌的解锁条目前置隐藏**：在拿到 Randomazzo 之前，游戏内不会出现秘法牌相关内容与条目（防信息过载）；暗·秘法牌同理，在拿到 Darkasso 前不出现。
5. **Reroll 不会重复出选项**：秘法牌抽取与普通升级三选一的 Reroll 行为不同——普通升级可以刷回之前出现过的选项，秘法牌抽取**不会**。这实际上让 Reroll 在秘法牌抽取里更"值钱"。
6. **秘法牌与 PowerUp 的 Reroll 是两套入口**：秘法牌抽取用的是同一份 Reroll 资源，所以"用 Reroll 刷秘法牌"会消耗掉升级用的 Reroll——这是需要玩家权衡的资源竞争。
7. **Inverse 商人卖秘法牌不受张数限制**：因此 Inverse + Endless 是"收满全部秘法牌"的主要途径。
8. **Room 1665 的特殊性（Darkasso 所在地）**：该关卡开局**没有秘法牌选择**，除 Arcanas 与 Limit Break 外的所有修饰全部禁用；靠击杀数（100/200/…/1665）逐间开门，第一间之后的房间里才有秘法牌宝箱。
9. **秘法牌不能被 Seal / Banish 针对**：Seal（封印）的官方不可封印清单里**明确包含 Arcanas**，Banish 只作用于升级候选的武器与被动道具。**Reroll 可以用于秘法牌抽取**——但被 Reroll 掉的选项会**从该宝箱的池中永久移除**，同一宝箱内不会再出现（所以秘法牌抽取里的 Reroll 是"单向消耗"）。
10. **携带秘法牌宝箱的 Boss 是具体敌人**：普通 30 分钟关卡是 **Pipeestrello 4（俗称 Glowing Bat）**；Whiteout 图用的是 **Pipeestrello 5（Silver Bat）**。这些 Boss 的生成条件带 "Only spawns if Arcanas are enabled" 标记——**再确认一次：关闭秘法牌 = 整只 Boss 不存在**。
11. **非 30 分钟关卡的时间点存在来源差异**：`Arcanas` 页只列了 Boss Rash / Bat Country / Tiny Bridge 的 **5:00 与 10:00**；而敌人页额外给出 **Carlo Cart 5:00 / 10:00** 与 **Whiteout 7:00 / 14:00**。两处不一致，本文并记，复刻时建议以实机为准。
12. **觉醒顺序敏感的例外**：Prismatic Missile / Luminaire **只有在 II - Twilight Requiem 早于 XIV - Jail of Crystal 和/或 XIX - Heart of Fire 被选中时**，才受 Twilight Requiem 的"到期爆炸"影响。也就是说秘法牌的**获取顺序会改变效果是否生效**——复刻时如果忽略这一点，会出现"同一套卡、不同顺序、效果不同"的不可复现行为。

## 六、暗·秘法牌（Darkanas）

Darkana 是 2024 年 8 月（Patch 1.11）随 Room 1665 一起加入的**第二套秘法牌**，共 **12 张**，与基础秘法牌**共用同一套机制**（同样的开局三选一与宝箱抽取、同样以罗马数字编号、同一个卡池），但主题与解锁方式完全不同。

**框架性事实**：

| 项目 | 内容 |
| --- | --- |
| 数量 | 12 张 |
| 解锁钥匙 | 遗物 **Darkasso**（Room 1665 最深处，累计击杀 1665 只后自动拾取；Room 1665 需用咒语 `forbiddenbox` 解锁） |
| 赠送卡 | 拾取 Darkasso 直接获得 **VI - Moonlight Bolero (Darkana)** |
| 与基础秘法牌的关系 | 共同构成同一个选择池（开局可在"已解锁的秘法牌或暗·秘法牌"中任选）；计数合并后 ≥23 张才会触发"6 选 1 + 免费 Reroll" |
| 系统可见性 | 未取得 Darkasso 前，暗·秘法牌**既不能解锁也不能启用**（Darkasso 的官方描述就是 "Enables the unlocking and activation of Darkanas"）；取得后开局可选卡池才扩大到包含暗·秘法牌 |

### 6.1 官方的定性：机制相同，只是主题不同

Patch 1.11（2024-08-16）Steam 公告原文：

> *There are currently 5 unlockable Darkanas in the game. You can access Darkanas by pressing the new button on the usual Randomazzo screen. **The only difference between Arcanas and Darkanas is their theme, functionally they are exactly the same.***

这句话要**当真**：两者共用同一套卡池、同一套抽取与结算逻辑、同一套开局三选一界面（只是界面多了一个切换按钮）。它们**不是"两套规则"**。

那么它们真正的差别在哪里？只有两处，且都不是"机制"层面的：

| 维度 | 实测差异 |
| --- | --- |
| **解锁语言** | 基础 22 张是**数值门槛**（「用 X 角色达到 50 级」/「在 Y 关卡坚持到 31:00」），且只需练级/熬时间；12 张暗·秘法牌是**理解门槛**（「用 X 角色触发 Y 武器的升级形态」），要求先玩懂特定 DLC 武器的进化链，条件更刁钻 |
| **设计取向（内容层面）** | 暗·秘法牌大量引入**赌博（XIII 老虎机）、货币即生命（0 号）、地形穿越（VIII）**等基础秘法牌没有的题材；这是"主题不同"带来的自然结果，而不是规则不同 |
| **编号成对（仅为社区观察）** | 暗·秘法牌刻意复用与基础秘法牌相同的编号，语义上常呈**反转/补完**关系（如 0 号 Game Killer ↔ 0 号 Stake to Your Heart）。wiki 明确指出「暗·秘法牌是其同号秘法牌的反面」**只是推测，官方从未确认**，且官方原话已否定了"功能上互为反面" |

**对基础秘法牌体验最实质的影响**：暗·秘法牌也计入总数，因此**只要解锁 1 张暗·秘法牌，总卡数就 ≥23**，立刻触发「宝箱 6 选 1 + 每次免费 1 次 Reroll」的强化规则。

### 6.3 带"代价"与不带"代价"的暗·秘法牌

**卡面效果本身含负面代价的（7 张）**：
1. **XIII Call of a Mad Moon**：Curse 符号令当前全部敌人移速与生命各 **+10%**；wiki 直言该符号"除非四连否则纯粹有害"，而高 Curse 会**提高滚到它的概率却不保证四连**——在 Curse 流构筑里可能是净负面。
2. **VIII Edge of the Earth**：移速被**钉死在 +100%**；自动吸宝箱被 wiki 明说是双刃剑（可能在你没准备好进化时把进化箱吸来）。
3. **0 Stake to Your Heart**：停止用经验宝石升级；受伤改为**先扣本局金币**。是 12 张里对构筑限制最强的一张。
4. **V Pale Diamond Incursion**：Gatti Amari 会**失去猫打架云雾**（但同时不再自伤）。
5. **XII Crystal Cries**：与 Sole Solution 同用可能有害（已收集的水晶魂在无形化期间仍占 200–250 上限）。
6. **XIX Heir of Fate**：与 XIX Heart of Fire 的"火焰"判定不一致，同时围绕两张卡构筑会很纠结。
7. **VI Moonlight Bolero**：概率随状态浮动（秘法牌满 3 张时蓝色 Boss 概率 10% → 5%），但仍在给收益，属于"代价很轻"。

**卡面效果不含负面代价的（6 张）**：**III Hidden Anathema**（代价是随机性与依赖食物来源）、**VI Moonlight Bolero**、**I Sapphire Mist**、**X Hail from the Future**、**XXI Wandering the Jet Black**、**XVIII Victorian Horror**。

> 注意区分：**XVIII Victorian Horror** 与 **0 Stake to Your Heart** 的"代价"更多体现在**解锁条件**上——前者要求**不带任何主动武器**打满 30 分钟，后者效果本身就是升级限制。

### 6.4 暗·秘法牌折射出的设计思路

1. **解锁条件从"数值门槛"升级为"理解门槛"**：要求玩家先玩懂某个 DLC 武器的进化链，甚至要求"在 Inverse + Boss Rash + 随机事件 + 随机升级下存活 15 分钟"这种复合挑战。**解锁条件本身就是教学内容**，教的是"怎么把游戏玩到极限"。
2. **多数卡明码标价一个代价**（12 张里 7 张，见 6.3）：移速被锁死、概率被自身属性拉偏、依赖不易控制的食物掉落。这是给老玩家提供"新的限制"，而不是"新的强度"——与基础秘法牌里 Game Killer 的思路一脉相承，但更系统化。
3. **把"运气"做成可控资源**：XII 与 XIX 把"冻结""火焰"这些**状态**变成"掉落货币"；XIII 干脆把四项经济属性（Growth / Greed / Luck / Curse）变成老虎机权重——**你堆什么属性，就更常滚出什么符号**，把既有属性系统接到了新机制上。
4. **代价与收益常常共用同一个旋钮**：XIII 的"高 Curse 更容易滚出负面符号"、VIII 的"吸宝箱方便但打乱进化节奏"。这类"同一个机制既是好处也是坏处"的设计，比基础秘法牌更难做，也更有回味。
5. **编号复用形成了成对的记忆锚点**（注意：这是内容/叙事层面的安排，**不是机制差异**）：
   - **0 - Game Killer（愚者）↔ 0 - Stake to Your Heart**：都用"停止经验"改写成长线，但前者把经验宝石变成爆炸物，后者把金币同时变成血量与伤害池。
   - **VI - Sarabande of Healing（治疗转伤害）↔ VI - Moonlight Bolero（每分钟一个藏宝 Boss）**；**X - Beginning（主武器 +3）↔ X - Hail from the Future（升级掉道具）**；**I - Gemini（复制武器）↔ I - Sapphire Mist（武器有几率连开两枪）**；**III - Tragic Princess（移动减 CD）↔ III - Hidden Anathema（食物给随机属性）**。
   - 34 张卡因此在玩家心里形成**成对的锚点**，而不是 34 个孤立条目——这是很值得学的卡牌组织方式。**但官方只把它们当作同一套系统的两批主题皮肤**，不要把"编号镜像"当成"规则对立"来实现。

## 七、如果我方要复刻这套系统：数据模型与优先级建议

### 7.1 数据模型（建议）

一张秘法牌的配置至少要能表达：

| 字段 | 用途 | 例子 |
| --- | --- | --- |
| `id` / `roman` | 编号（含 0 号）与排序 | `T09_DIVINE`, `IX` |
| `name` / `desc` | 名称与卡面文案 | — |
| `targets` | **受影响的武器族**（用族标签而非具体武器名，便于容纳进化版） | `["Cross","KingBible","Garlic",...]` |
| `trigger_type` | 触发器类型：`Always` / `Periodic` / `OnEvent` / `Rule` | 见第三节分类表 |
| `trigger_param` | 周期秒数或事件名 | `120.0`、`OnProjectileExpire`、`OnHeal` |
| `stat_mods` | 属性层修改（加法/乘法分开记） | `{might_add:0, area_mul:1.25}` |
| `hooks` | 需要挂到武器/伤害/移动事件上的回调名 | `["OnHit","OnKill"]` |
| `counter_or_state` | 需要跨帧保存的状态（层数、循环相位、已消耗次数） | `{phase:0.0, cycle:10.0}` |
| `conflicts` | 与其他秘法牌/进化形态的互斥或覆盖关系 | 「进化为 X 后失效」 |
| `negative` | 是否为负面/中性卡（供 UI 与 AI 提示） | `true` |

**关键实现约束（比数据字段更重要）**：

1. **只做一条属性重算管线**。所有来自武器、被动、PowerUp、秘法牌的加成必须在**同一个函数**里按固定顺序叠加，且**每次重算从基础值开始**。否则"震荡型"秘法牌（V、XVIII）与"每级 +1%"类效果会互相污染，出现数值漂移和难查的 bug。
2. **武器族标签化**。秘法牌大量使用"卡面列出的武器"，且**基础武器与进化版常常共享、也常常不共享**同一张卡（例如 Divine Bloodline 主要惠及未进化武器，Twilight Requiem 惠及一部分进化）。所以配置里必须能分别声明"基础武器 / 进化版 / 联合版"。
3. **周期触发器要有统一时钟**。VIII（每 2 分钟）、V / XVII / XVIII 与 XIII（10 秒周期）、XXI（伤害区 2 秒冷却）等如果用各自独立计时器，暂停、加速（Hurry）、时间缩放会各自跑偏。建议全部挂在一个**游戏内时钟**上，用"上次触发时间戳"计算——尤其 VIII 是按**游戏内计时器的偶数分钟**触发，而不是"拾取后每 2 分钟"。
4. **`OnProjectileExpire` 这类事件需要显式设计**。多数引擎默认只有"命中"事件没有"过期"事件，II - Twilight Requiem 依赖"投射物自然消失"触发爆炸，需要在投射物生命周期结束时统一发事件。
5. **震荡型效果的实现方式**：不要每帧乘算，改为"重算时注入一个当前相位系数"，避免浮点累积误差与 UI 数字抖动。

### 7.2 复刻优先级（按性价比排序）

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| **P0** | 系统骨架：关卡开关、开局"全卡池选一"UI、11:00 / 21:00 秘法牌宝箱、3 张上限、4 选 1 与 ≥23 张后的 6 选 1 + 免费 Reroll | 没有这套骨架，单张卡做得再好也体验不到"秘法牌系统" |
| **P0** | A 类（常驻属性）中的 4–6 张：X Beginning / XVIII Boogaloo / V Chaos / XI Waltz / VII Iron Blue Will / XIV Jail of Crystal | 只需要"属性重算 + 弹射/冻结标记"，是验证属性管线正确性的最小集合 |
| **P1** | C 类事件型：VI Sarabande / XIX Heart of Fire / II Twilight Requiem | 需要伤害/回血/投射物事件钩子，做完这套钩子，后续卡都能复用 |
| **P1** | IX Divine Bloodline / XXI Blood Astronomia | 机制最"华丽"、最能体现秘法牌价值的两张，但依赖较完整的护甲/反击/Magnet 体系 |
| **P2** | 规则型：0 Game Killer / XX Silent Old Sanctuary / XIII Wicked Season / XV Disco of Gold | 需要"资源与槽位规则"分支，且 Game Killer 会与升级系统强耦合 |
| **P3** | I Gemini（对应武器）| 工作量最大：要为每把受益武器实现一个"镜像武器"，或做参数化复制。建议先只支持少数几把武器 |
| **P3** | 12 张暗·秘法牌 | 依赖暗·秘法牌的解锁任务体系；若本项目按"基础功能开局全解锁"处理，则只做效果、不做解锁任务，成本会下降 |

> **本项目特有的一条简化机会**：`Docs/00-profile.md` 已定下"基础功能一开始就全部解锁"，因此**可以整块砍掉秘法牌的解锁条件体系**（Randomazzo 拾取、角色 50 级、31:00、Darkasso 与 Room 1665 任务链），只保留"卡池 + 局内获取 + 效果"。这会显著降低成本，但也会丢掉"秘法牌的存在感来自发现"这层体验——建议保留"至少一张初始秘法牌 + 卡池逐步开放"的轻量解锁作为可选开关。
