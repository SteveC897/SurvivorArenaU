## 二、经验与升级

### 2.1 经验曲线

实现于 `Gameplay/ExperienceSystem.GetXpToNext`：

| 等级区间 | 升到下一级所需 |
| --- | --- |
| 1 → 2 | 5 |
| 2 → 20 | `5 + (level-1) × 10`（2→3 为 15，19→20 为 185） |
| 20 → 21 | 785（19→20 的 185 + 额外 600） |
| 21 以后 | `785 + (level-20) × 13` |

- 5 分钟局一般到 **13–16 级**，20 级节流阀基本不触发；
- `XpToNext`、`Level`、`PendingLevelUps` 通过 `ExperienceChangedEvent` 通知 HUD；
- 一次拾取可跨多级，`PendingLevelUps` 保证每次升级都弹一次三选一。

### 2.2 经验宝石

实现于 `Gameplay/PickupSystem`：

- 敌人死亡时按 `EnemyKilledEvent.Xp` 掉落（普通蝙蝠 1，宝箱蝙蝠 30）；
- 场上上限 **256**，超出移除最早生成的一颗；
- 玩家 `Magnet` 属性决定吸附半径：`2.0 × Magnet`；
- 吸附速度从 2 加到 12（先慢后快），进入 0.6 拾取半径后发布 `XpGemCollectedEvent`；
- 表现由 `CombatPresenter` 画绿色/红色宝石；红色用于 ≥10 XP 的大宝石。

### 2.3 三选一规则

实现于 `Gameplay/UpgradeSystem`：

- 候选池：
  - 已持有且未满级武器（权重 ×3）；
  - 未持有且武器槽未满的新武器（权重 ×1）；
  - 已持有且未满级被动（权重 ×3）；
  - 未持有、被动槽未满、且 `PassiveDefinition.Offered = true` 的新被动（权重 ×1）。
- 整数权重加权随机，固定 seed；同一次三选一不重复；
- 最多 3 张卡；若候选不足 3 张就显示实际数量；没有候选时消费本次升级并关闭，不卡死；
- 已满级武器/被动不再出现；槽满后不再出现新武器/新被动；
- 选中后：
  - 新武器：加入 `Loadout`，从 Lv1 开始，下一帧进入 `WeaponSystem` 冷却；
  - 武器升级：复用同一个 `WeaponRuntime`，等级 +1；
  - 新被动：加入并注册 `sourceId = passive.<id>` 修改器；
  - 被动升级：同一 source 用 `SetModifierValue` 更新累计值，不叠加多条。
- 升级暂停：`UpgradeSystem.IsChoosing` 为 true 时，`BattleBootstrap` 跳过计时/移动/刷怪/武器/拾取/宝箱，并 `GamePause.SetPaused(true)`；`EnemyBat.Update` 读 `GamePause` 停止推进。**不是 Time.timeScale = 0**。
- UI：`LevelUpView` 订阅 `LevelUpOfferedEvent`，点击卡片或按 1/2/3 发布 `LevelUpChoiceEvent`；`BattleBootstrap` 不引用 UI。

## 三、武器（10 把）

所有武器共用 `Gameplay/WeaponSystem` 的集中冷却调度；伤害/冷却/范围/飞射速度/持续时间/数量分别乘/加 `Stats` 的 Might / Cooldown / Area / ProjectileSpeed / Duration / Amount。

> `Area`、`Speed`、`Duration` 的具体逐级值见 `ContentCatalog.asset` 的 `WeaponDefinition.Levels`。

### 3.2 强能魔杖（初始）

- 8 级；L1 伤害 10、CD 1.2、单发、穿透 1；
- L2/L4/L6 各 +1 发；L3 CD −0.2；L5/L8 各 +10 伤害；L7 穿透 +1；
- 实现：`GetNearestEnemies(amount)` 取最近敌人；弹体直线飞行，命中扣血，穿透归零销毁；
- 默认 `ProjectileLifetime 2.5s`、`BaseProjectileSpeed 8`；吃 Might/Cooldown/Area/ProjectileSpeed/Amount；
- 不吃 Duration（数据 Duration=0）。

### 3.3 其余武器的行为落点

- **飞刀**：以 `PlayerMotor.Facing` 为基准，按 `Amount` 做小角度扇形；同一帧生成；
- **神鞭**：`AreaEffectSystem.SpawnRectangle`，`Amount ≥ 2` 时前后各一段；矩形按面向旋转；
- **斧头**：弹体初速向上 + 水平偏移，`Gravity = -18`；`Duration` 1.5s；
- **国王圣经**：`OrbitEffectSystem`，环半径 `1.7 × Area`，持续 `Duration`，每 1.7s 对环带内敌人结算；武器冷却设为“持续结束 + CD”；
- **火焰魔杖**：每个火球随机选一个存活敌人；无目标时随机方向；
- **大蒜**：以 `BattleConfig.GarlicBaseRadius（2）× Area` 为半径的瞬时圆形伤害；
- **圣徒水**：在玩家周围 2–4 单位随机落点，圆形区域持续 `Duration`，每 0.5s 结算；
- **痕印石**：弹体 `Bounce=true`，碰相机视口边缘反弹；命中后穿到下一敌人；`Duration` 作为寿命；
- **闪电戒指**：随机敌人位置生成短寿命圆形范围，`Area` 决定半径。

### 3.4 武器升级/进化

- 升级：`WeaponRuntime.Level++`，读下一行 `WeaponLevelStats`；不重建对象；
- 进化（暂缓）：预留在 `WeaponRuntime` 上换 `Definition`/行为，并清理旧 `weapon.<id>` 修改器；本次未实现。

## 五、宝箱

实现于 `Gameplay/ChestSystem`：

### 5.1 出现规则

| 时间 | 宝箱蝙蝠 HP | 奖励位 |
| --- | --- | --- |
| 1:00（60s） | 120 | 1 |
| 2:30（150s） | 240 | 3 |
| 4:30（270s） | 360 | 5 |

- 宝箱蝙蝠在距主角 7 单位的随机方向生成，体型 ×1.8、金色染色；
- 不参与离屏回收；会计入当前波次活跃数量；
- 被击杀时在死亡位置掉宝箱，玩家走到 1.2 单位内自动打开；
- 5:00 清场时不会再掉经验/宝箱（`EnemySpawner.KillAll` 内 `_clearing`）。

### 5.2 奖励

- 奖励位 N 表示直接调用 N 次 `UpgradeSystem.GrantChestRewards` 的随机升级；
- 奖励池与三选一相同：未满级武器升级 + 新武器 + 未满级被动 + 新被动；不受“本次不重复”限制，同一件被动可以在一个 5 位宝箱里连升；
- 不弹三选一，不暂停；HUD 显示 `ChestOpenedEvent.Summary`（例如「宝箱：大蒜、痕印石、烛台」）；
- 没有可升级项时给 25 XP 保底；
- 超武进化暂缓：当前宝箱只给普通升级。

## 六、如何接新内容

### 6.1 加一把武器

1. 在 `WeaponBehavior` 加枚举（或复用现有行为）；
2. 在 `Assets/Data/ContentCatalog.asset` 的 `weapons` 里加一个 `WeaponDefinition`：
   - `Id`、中文名、图标、弹体图标、`Behavior`、`Weight`；
   - `Levels` 填 8 级 `WeaponLevelStats`；
3. 若用新行为：在 `WeaponSystem.Fire` 加一个 `case`，调用 `ProjectileSystem`/`AreaEffectSystem`/`OrbitEffectSystem`；
4. 不需要改 HUD/Presentation；槽位和升级卡会自动读内容目录。

### 6.2 加一件被动

1. 在 `PassiveEffect` 加属性映射（若现有 10 个不够）；
2. 在 `ContentCatalog` 加 `PassiveDefinition`：`Effect`、`ModifierKind`、`LevelValues`、`MaxLevel`、`Offered`；
3. `Loadout.ApplyPassive` 会自动映射到 `StatType`，用 `sourceId = passive.<id>` 注册；
4. 不需要改升级系统/UI。

### 6.3 改初始武器

`BattleBootstrap.Start` 里：

```csharp
WeaponDefinition startingWeapon = catalog.FindWeapon("magic_wand");
```

把 `"magic_wand"` 换成想要的武器 `Id` 即可；当前需求保持强能魔杖。

### 6.4 接超武进化（后续）

- 在 `ContentCatalog` 加进化配方（基础武器满级 + 被动 + 宝箱）；
- 宝箱奖励命中配方时，不调用普通 `GrantChestRewards`，而是：
  - 复用原 `WeaponRuntime`，替换 `Definition`/行为；
  - 清除旧 `weapon.<id>` 来源的修改器；
  - 保持同一实例，避免引用失效；
- `ChestSystem`/`UpgradeSystem` 需要新增“进化候选”分支；本次不做。

### 6.5 接秘法牌/玩家受伤/跳过重选

- 秘法牌：按 `Docs/吸血鬼幸存者-秘法牌系统详细解析.md`，通过 M2 修改器 + M3 事件钩子；当前无实现；
- 玩家受伤：新增 `PlayerHealth`/`DamageSystem`，把 Armor/MaxHealth/Recovery 接上，再把三件防御被动 `Offered=true`；
- 跳过/重选：在 `LevelUpView` 加两个按钮，`UpgradeSystem` 维护次数并按文档“重选把已刷掉的选项移出本次池”；当前暂缓。

## 八、与原作/文档的差异

1. **5 分钟压缩**：原作 30 分钟/31 分钟节点，本场景 5 分钟/30 波；宝箱时间与奖励位按 5 分钟压缩。
2. **没有玩家受伤**：防御被动不提供；主角不会被撞死。
3. **没有超武进化/秘法牌/跳过重选/排除**：按 `00-profile` 暂缓。
4. **部分武器机制简化**：
   - 暴击、击退、飞刀间隔、圣经逐本书独立命中、圣水随机落点细节未逐项实现；
   - 国王圣经用“环带每 1.7s 结算”代替逐本书碰撞；
   - 痕印石反弹后允许再次命中，但没有严格的 0.5s 同敌人重复命中间隔。
5. **数值**：10 把武器按文档首批实现表的 L1/满级与主要成长项填入 `ContentCatalog`；
   未实现的暴击/击退字段保留在 `WeaponLevelStats` 中，方便后续接伤害系统。
6. **表现**：Boss 是放大染色的蝙蝠，宝箱/区域圈/弹体使用运行时图形或武器图标；没有专门的 Boss/宝箱美术。
