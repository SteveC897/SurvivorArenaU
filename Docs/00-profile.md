# 项目概况（00-profile）

> 本文是项目的**范围基准**：做什么、不做什么、界面照哪张图做。
> 范围一旦变更，先改本文，再改代码。其他文档（如《秘法牌系统详细解析》）只提供原作机制资料，不代表本项目范围。

---

## 一、项目定位

| 项目 | 内容 |
| --- | --- |
| 引擎 | **Unity 2022.3.62f3c1**（从 Godot 4.7.2 mono 迁移过来） |
| 渲染 | **GL Compatibility**，Windows 下使用 D3D12 驱动 |
| 视觉 | 《吸血鬼幸存者》原作的 **2D 像素风格**（俯视角 2D 管线） |
| 目标 | 复刻《吸血鬼幸存者（Vampire Survivor）》的功能 |

三条基本约定：

1. **以"全部解锁"的状态呈现**。原作的解锁链（成就、遗物、棺材、金币 PowerUp、角色 50 级、关卡 31:00 等）**不实现**——基础功能开局即可用，不随关卡推进逐步解锁。
2. **范围由开发者界定，其余一律砍掉**。本文"保留系统范围"之外的内容默认不做；全部做完本身不现实，因此**明确不做的部分与要做的部分同等重要**（见第五节）。
3. **已砍掉 HD2D**。曾评估把视觉改为 HD2D（参考《八方旅人》），现已放弃，故景深、体积雾、泛光等服务于 3D 混合渲染的特性不在范围内；**不需要切换 Forward+**。

---

## 二、保留系统范围

一句话概括：**只做一关、一个人物，但把这一关涉及的系统全部做完整。**

| 维度 | 范围 |
| --- | --- |
| 地图 | **仅一关**：「疯狂森林」（原作第一关，Stage 1），规格与原作一致（30:00 时限、波次时间轴、掉落） |
| 人物 | **仅一个**：「伊梅尔达」（Imelda），**开局武器：强能魔杖**（官方译名） |
| 保留的系统 | 开始、收藏、邪魔图鉴、小地图（局内暂停界面）、超武合成配方、秘法牌、计时二倍速（关卡选择界面的"倍速"）、移速二倍速（关卡选择界面的"血战"） |
| 不保留 | 其余关卡、其余角色、Adventures、Inverse、Endless、Limit Break 等（见第五节） |

## 三、各系统规格

### 3.1 开始（主菜单 → 角色选择 → 关卡选择）

**主菜单**（参考截图 10）：`开始`、`快速开始`、`在线`、`冒险`，底部功能条 `制作团队 / 邪魔图鉴 / 收藏 / 强化 / 战绩 / 秘密`，顶栏显示玩家名与金币。
本项目只做其中一条主线：**开始 → 角色选择 → 关卡选择 → 进入游戏**；`快速开始`、`在线`、`冒险`、`战绩`、`秘密`均不做。

**角色选择**（参考截图 08）：

- 角色列表**只保留"伊梅尔达"**（其余格子留空或不做）。
- 左侧为属性总览面板（生命上限 / 恢复 / 防御 / 移动速度 / 力量 / 飞射速度 / 持续时间 / 攻击范围 / 冷却时间 / 发射数量 / 复活机会 / 念力 / 运气 / 成长 / 贪欲 / 诅咒 / 重选 / 跳过 / 排除），底部显示**武器上限：6**。
- 右下为角色详情：`伊梅尔达 贝尔帕斯`，被动"**每 5 级，获取经验值 +10%，最多 +30%**"，以及**开局武器「强能魔杖」**的图标。
- 按钮：`角色配置`。

**关卡选择**（参考截图 09）：

- 关卡列表**只保留"疯狂森林"**（Stage 1，副标题"魔堡是一个谎言，但这里有免费的烤鸡，所以也挺好。"）。
- 左侧：关卡神器、时间上限 30:00、计数倍速、移动速度、金币加成、运气加成、经验加成、敌人血量。
- 底部三个**可勾选**开关：**血战**（移速二倍速）、**倍速**（计时二倍速）、**秘能**（秘法牌总开关，勾选后本局才会出现秘法牌与携带宝箱的 Boss）。

- **只做第一关"疯狂森林"出现过的怪物**，图鉴内容（名称、立绘、简介、生命值、能力、速度、耐性、技能、出没地点）**与原作保持一致**。

### 3.4 小地图（局内暂停界面）

- 局内暂停时的界面，参考截图 14。
- 组成：中央**小地图**（可缩放，`+` / `−`；有边界框、玩家/敌人/拾取物标记）、左侧属性面板、右上装备栏、右侧秘法牌栏、底部按钮 `选项 / 隐藏拾取物 / 隐藏宝物方位 / 打开秘典 / 继续`。

### 3.5 超武合成配方

- 参考截图 15：标题 `武器进化与组合`，三列排布"**基础武器 + 被动道具 = 进化武器**"的配方，底部翻页 `1 / 2`。

## 七、已定案与待办
