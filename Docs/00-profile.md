# 项目概况（00-profile）

> 本文是项目的**范围基准**：做什么、不做什么、界面照哪张图做。
> 范围一旦变更，先改本文，再改代码。其他文档（如《秘法牌系统详细解析》）只提供原作机制资料，不代表本项目范围。
>
> **2026-10-31 范围收缩**：只做战斗场景内的内容；战斗场景以外的界面与系统全部不做。详见第二、五、六节。

---

## 一、项目定位

| 项目 | 内容 |
| --- | --- |
| 引擎 | **Unity 2022.3.62f3c1**（从 Godot 4.7.2 mono 迁移过来） |
| 渲染 | **URP 14 + 2D Renderer**，像素完美 640×360 / 32 PPU |
| 视觉 | 《吸血鬼幸存者》原作的 **2D 像素风格**（俯视角 2D 管线） |
| 目标 | 复刻《吸血鬼幸存者》的**局内战斗**：一关、一个人物 |

四条基本约定：

1. **只做战斗场景**。主菜单、角色选择、关卡选择、收藏、邪魔图鉴、强化目录、战斗数据结算等**场景外界面一律不做**；游戏启动直接进入战斗。场景内的 HUD、升级三选一、暂停菜单、胜利面板属于战斗场景，保留。
2. **以"全部解锁"的状态呈现**。原作的解锁链（成就、遗物、棺材、金币 PowerUp、角色 50 级、关卡 31:00 等）**不实现**——基础功能开局即可用，不随关卡推进逐步解锁。
3. **范围由开发者界定，其余一律砍掉**。本文"保留系统范围"之外的内容默认不做；全部做完本身不现实，因此**明确不做的部分与要做的部分同等重要**（见第五、六节）。
4. **已砍掉 HD2D**。曾评估把视觉改为 HD2D（参考《八方旅人》），现已放弃，故景深、体积雾、泛光等服务于 3D 混合渲染的特性不在范围内；**不需要切换 Forward+**。

## 二、保留系统范围

一句话概括：**只做一关、一个人物，且只做战斗场景内的系统。**

| 维度 | 范围 |
| --- | --- |
| 地图 | **仅一关**：「疯狂森林」（原作第一关，Stage 1），规格与原作一致（30:00 时限、波次时间轴、掉落） |
| 人物 | **仅一个**：「伊梅尔达」（Imelda），**开局武器：强能魔杖**（官方译名） |
| 局内系统 | 移动、刷怪、击杀、武器、经验与升级、局内属性成长、跳过/重选（暂缓）、超武进化（暂缓）、ESC 暂停、HUD、胜利面板 |
| 场景外 | **全部不做**（见第五节） |

**边界说明**：

- **战斗场景 = 局内主画面 + 叠加界面**。HUD、升级三选一、暂停菜单、胜利面板都属于战斗场景，保留。
- **场景外 = 全屏菜单与流程**。主菜单、角色选择、关卡选择、收藏、邪魔图鉴、强化目录、战斗数据结算等全部不做。
- 没有主菜单：启动即进入战斗；「退出」从暂停菜单直接结束游戏。
- 武器、经验、升级等局内系统**尚未实现**，按顺序排期（见第八节）。

## 三、局内系统规格

### 3.1 局内暂停（ESC）

**本次新增；替代原「ESC 退出游戏」的设计。**

- 触发：按 `Esc` 进入暂停界面，**不再用 Esc 退出游戏**。
- 界面：居中面板，显示「**已暂停**」字样；下方两个按钮「**继续**」「**退出**」。
- 光标：默认选中「继续」；可用 `↑` / `↓` 或 `W` / `S` 移动；鼠标移入按钮时**光标跟随鼠标**；按 `Enter` 或**鼠标左键点击**触发当前按钮。
- 「继续」：关闭暂停界面，恢复战斗。
- 「退出」：结束游戏（没有主菜单可回）。
- 暂停期间：计时、波次、刷怪、移动、攻击、拾取全部冻结；暂停界面本身仍可正常操作。
- **不做**：原作暂停界面的小地图、属性面板、装备栏、秘法牌栏、选项、隐藏拾取物、隐藏宝物方位、打开秘典、武器进化与组合。

### 3.2 升级三选一与跳过/重选（暂缓）

- 升级三选一界面属于战斗场景内的叠加界面，随武器/成长系统一起实现。
- **跳过 / 重选：默认可用，要做，但暂时不做。** 等武器系统与局内升级/属性成长实现后，再接这两个按钮。
- 次数来源：不从 PowerUps（局外强化）购买；默认次数与规则待定。
- **排除（Banish）：未定**，暂不实现。
- 参考截图 13（重选/跳过按钮的位置与样式）。

### 3.3 其他局内系统

- 武器（强能魔杖）、经验、局内属性成长：规格另文，尚未实现。
- HUD、胜利面板的现有规则与数值见 `01-测试战斗场景.md`。

## 六、暂缓（当前不做，后续视情况恢复）

| 项 | 当前状态 | 恢复条件 |
| --- | --- | --- |
| **秘法牌** | **整套暂不做**：卡池、开局选卡、宝箱、秘能开关、全部界面与数值 | 未定。机制资料保留在 `Docs/吸血鬼幸存者-秘法牌系统详细解析.md`，不代表已列入当前范围 |
| **超武进化** | **可以做，但时间可能来不及，先不实现** | 时间允许时；依赖武器、被动道具、宝箱 |
| **跳过 / 重选** | 默认可用、要做，但暂不做 | 武器系统与局内升级/属性成长实现后 |
| **排除（Banish）** | 未定 | 与跳过/重选一起评估 |

**超武进化的简化机制**（详细规则与完整配方见 `Docs/吸血鬼幸存者-本体武器与被动系统详解.md` 第五节）：

- 每把基础武器都绑定一个特定被动，或另一把特定武器。
- 同时持有基础武器与对应物，并把基础武器升到满级；双武器配方则两把都要升满；部分配方还要求对应被动也满级。
- 通过银/金宝箱获得强化时，其中一个强化选项有较高概率被替换成对应的超武。
- 选中后，基础武器从背包移除（双武器配方时两把素材武器都移除），超武加入背包。
