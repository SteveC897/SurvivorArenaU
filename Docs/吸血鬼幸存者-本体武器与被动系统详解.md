## 一、背包与槽位系统

### 1.1 两条容量线

一局内玩家的"背包"由两条互不相通的容量线组成：

| 容量线 | 上限 | 说明 |
|---|---|---|
| **武器槽** | **6** | 从升级三选一中获得的武器上限 |
| **被动槽** | **6** | 从升级三选一中获得的被动道具上限 |

两条线**各自独立计数**：塞满 6 把武器不会挤占被动位，反之亦然。达到上限后：

- **新武器**不再出现在三选一里；只能升级已有武器。
- **新被动**同样不再出现。
- 当"6 武器 6 被动全部满级、无可升级对象"时，三选一改为提供 **金币（Big Coin Bag）** 或 **烤鸡（Floor Chicken）**；若已开启 Limit Break，则改为继续升级满级武器。

> 细节：武器与被动在升级界面里是**同一个候选池**（按稀有度加权抽取），所以"武器 6 个"和"被动 6 个"是两个独立的硬上限，但在抽取时共享概率空间。

### 1.2 突破上限的合法途径

上限不是绝对的。本体内有这些例外：

| 途径 | 效果 |
|---|---|
| **舞台道具（Stage items）** | 每张地图固定刷出的被动道具，**捡取时无视 6 个上限**，直接变成额外的被动，且之后仍能从升级中继续升级 |
| **金色宝箱（Gold chest）** | 可给出玩家**尚未拥有**的武器（作为掉落物出现在地面，需要走过去捡） |
| **暗宝箱（Dark chest）** | 50% 概率给一个**尚未拥有的被动**（不看是否满级） |
| **Arma Dio** | 本体武器（**占武器位**，1 级），可选择一件额外被动；可用 Candybox 选它，从而在任何地图突破 6 个被动 |
| **Mindbender 遗物** | 解锁"最大武器数量"设置，可选范围 **1–6**（只能**降低**，不能超过 6），且**不改变**被动上限（固定 6） |
| **Survarot（Zi'Assunta 的 Gala 技能）** | 每累计获得 2.5k / 7.5k / 15k 金币各 +1 个被动槽（需 Survarocchi 遗物），之后每 15k 金币可再触发 |
| **Candybox** | 可选择任意已解锁的基础武器（占武器位，但绕过"池子里抽不到"的限制） |

舞台道具这条尤其重要：**它让"6 个被动"变成"6 + 地图白送"**。所以最优解通常是先用升级把 6 个被动填满，再去捡地图上需要的那个——捡到就是第 7 个。

### 1.3 三选一的实际规则

每次升级暂停游戏，给出 **3 个选项**；特定条件下出现第 4 个。

| 机制 | 规则 |
|---|---|
| 选项数量 | 3；**第 4 个选项的出现概率由 Luck 决定**：`1 − (1 / 总Luck)` → 满 Luck 时趋近 100% |
| 候选池权重 | 每个武器/被动有**稀有度（rarity）**值，被抽中概率 ≈ `该物品稀有度 / 池子总权重` |
| 优先给已有物品 | 先做 **2 次**"是否给已有物品"判定；命中则从已有物品里随机挑一个。概率 `(1 + 0.3x − 1) / 总Luck`，即 **`0.3x / 总Luck`**：等级为偶数时 x=2（Luck=100% 时 60%），奇数时 x=1（30%）。**注意：Luck 越高，越不容易被塞已有物品**（换来更多选择空间） |
| 不重复 | 同一次三选一里同一物品不会出现两次 |
| 已满级物品 | 满级后不再出现在池中 |
| 无法被抽取的物品 | 未解锁的武器/被动不会出现；被 **Banish / Seal** 掉的不出现 |

**为什么这条规则重要**：它意味着"把一条线养满"是**可控**的，而不是纯随机——但代价是 **Luck 会降低重复提议**，所以"堆 Luck 提高多样化"与"把某把武器练满"是两种相反的取舍。

> 池子总权重参考：Wiki 只给出**含全部 DLC** 的数字——武器池 8,130 + 被动池 1,370 = **9,500**。本体（不含 DLC）的总权重 Wiki 未给，实际更小，因此单件本体重武的实际被抽中概率高于按 9,500 估算的值。

> Seal 的禁区：不能封印遗物、至宝、经验宝石、金币、宝箱、Golden Egg、以及 Yellow Sign 产出的被动等。

### 1.4 五个构筑控制手段

本体通过 PowerUps 购买（金币，跨局永久）或角色自带获得：

| 手段 | 作用 | 局内表现 |
|---|---|---|
| **Reroll** | 重抽当前 3 个选项 | 每级 +2 次，最多 5 级（+10 次） |
| **Skip** | 跳过本次选择，换取经验 | 每级 +2 次，最多 10 次 |
| **Banish** | 把某物品从本次三选一移除，**本局内不再出现** | 每级 +2 次，最多 10 次 |
| **Seal** | 在**收藏菜单**里预先封印某物品，之后它不会出现在三选一与光源掉落里 | 需遗物解锁，最多 4 个 Seal 类 PowerUp |
| **Preserve** | Reroll/Skip/Banish 有概率不被消耗 | 每级 +10%，最多 50% |

- **Banish 是局内的、临时的；Seal 是跨局的、永久的。** 两者都会把物品从三选一池与光源掉落池中移除，但**不会阻止它作为初始武器/舞台道具/选择器（如 Candybox）出现**。通过这类方式拿到的已被 Seal/Banish 的物品，等同"1 级且不可升级"，直到你在地图上选"解除封印"才恢复正常升级。
- **Banish 没有绝对次数上限**：PowerUp 满级给 10 次，此外角色、至宝、金蛋都可能额外提供。
- 进阶玩法：进图前在 Collection 里把**整张地图的舞台道具**全部 Seal 掉，这样三选一池子里就不会被它们占位；进图后仍可在地图上捡到它们（选"解除封印"），等于**白拿等级又不污染池子**。

### 1.5 Limit Break（突破上限）

解锁条件：获得 **Great Gospel** 遗物（Cappella Magna 击败最终敌人掉落）。开启后，满构筑的三选一不再给金币/烤鸡，而是给**满级武器的额外属性**。

可选属性与上限（本体通用规则）：

| 属性 | 每次加成 | 总上限 |
|---|---|---|
| Might | +0.5%（部分武器 +0.3% / +1%） | 无上限 |
| Area | +2.5%（部分 +1% / +2%） | 1000%（部分 400% / 500%） |
| Speed | +5% | 300%（部分 200%） |
| Duration | +100ms | 按武器分档：2 / 3 / 6 / 9 / 10 / 15 秒 |
| Amount | +1 | 20（部分 5 / 10 / 30） |
| Pierce | +1 | 10 |
| Crit Chance | +2.5%（部分 +1%） | 100% |

- 上限针对**武器基础值**：例如 Knife 满级穿透 3，上限 10 → 只能再吃 7 次穿透。
- **Limit Break 后再进化，额外属性会全部重置**，进化武器从 1 级重新开始。
- Limit Break **不影响宝箱**：宝箱仍然只给金币。

### 1.6 宝箱：构筑的主要来源

宝箱由 Boss 掉落，是"变强"的第二条主通道。

**奖励位**：宝箱分 **1 / 3 / 5 个奖励位**三种，由每个 Boss 各自的配置决定，**Luck 只影响抽到高档宝箱的概率**。

```
实际概率 = 配置概率 × 总Luck
判定顺序：先判 5 位 → 失败再判 3 位 → 再失败则落到该 Boss 的保底等级
```

**金币**（基础值，受 Greed 加成）：

| 奖励位 | 金币范围 |
|---|---|
| 1 位 | 100–200 |
| 3 位 | 300–600 |
| 5 位 | 500–1000 |

**五种宝箱**（本体可遇到的）：

| 类型 | 外观 | 能力 |
|---|---|---|
| **青铜** | 普通 | 不能进化；通常是 10:00 前的 Boss 掉落 |
| **白银** | 银色 | **可以进化/合成**；通常是 10:00 后的 Boss 掉落 |
| **金色** | 金色 | 可给出玩家**尚未拥有**的武器（生成在地上需捡取）；1.14 起已移除进化与锁定武器 |
| **至宝** | 紫色 | 只能选至宝（Arcana），11:00 / 21:00 掉落；解锁 ≥23 张时给 6 选 1 |
| **暗** | 暗色 | 50% 等同青铜（固定 1 位）；50% 给一个尚未拥有的被动 |

**新手固定序列**：存档里**前 6 个宝箱固定为 1-1-3-1-1-5 位**，且这些开箱动画不可跳过。这是刻意的引导设计——第 6 个箱子直接给你 5 位奖励，用来展示"宝箱可以很好"。

**全满级之后**：所有奖励位替换为金色钱袋（每个 25 金币），数量受 Greed 影响；如果此时还没拿过 Candybox，每个钱袋有 1%（受 Luck 影响）概率变成 Candybox，每局仅一次，5 位宝箱必定触发。

## 二、属性系统

本体共 26 项属性（含 Seal），真正影响武器的是下面这 8 项"乘区"。所有属性均为**乘法叠加在武器基础值之上**，且**不是每把武器都吃所有属性**。

| 属性 | 基础值 | 上限 | 每点效果 | 主要来源（本体被动） |
|---|---|---|---|---|
| **Might**（威力） | 100% | 1000% | 伤害倍率 | Spinach、Torrona's Box、Omni |
| **Area**（范围） | 100% | 1000% | 攻击范围倍率 | Candelabrador、Silver Ring、Torrona's Box |
| **Speed**（弹速） | 100% | 500% | 投射物速度倍率 | Bracer、Torrona's Box |
| **Duration**（持续） | 100% | 500% | 效果持续时间倍率 | Spellbinder、Silver Ring、Torrona's Box |
| **Amount**（数量） | 0 | +10 | 额外投射物数量（**加算**，不是倍率） | Duplicator |
| **Cooldown**（冷却） | 100% | 10% | 冷却倍率（越低越快） | Empty Tome |
| **Move Speed**（移速） | 100% | — | 角色移动速度 | Wings |
| **Luck**（幸运） | 100% | — | 掉落、宝箱质量、暴击、第 4 选项 | Clover |

其余属性：

| 属性 | 基础值 | 作用 |
|---|---|---|
| Max Health | 100 | 生命上限（Hollow Heart / Metaglio Left） |
| Recovery | 0 /s | 每秒回血（Pummarola / Metaglio Left） |
| Armor | 0（上限 50） | 每次受击减伤（Armor 被动） |
| Magnet | 30 | 拾取吸附半径（Attractorb） |
| Growth | 100% | 经验获取倍率（Crown） |
| Greed | 100% | 金币获取倍率（Stone Mask） |
| Curse | 100% | 敌人速度/血量/数量/频率倍率（Skull O'Maniac、Gold Ring、Metaglio Right） |
| Revival | 0（上限 10） | 额外复活次数（Tirajisú） |
| Invulnerability Time | 240ms | 受击后无敌时间（Parm Aegis） |
| Charm | 0 | 每波敌人额外数量（Karoma's Mana） |
| Defang | 0% | 使部分敌人无法造成伤害 |
| Reroll / Skip / Banish | 0 | 见 §1.4 |
| Seal | 0 | 预先封印物品 |

> **关键理解**：武器的最终数值 = `基础值 × 对应属性倍率 + 等级加成`。所以"属性点"和"武器等级"是两条独立的成长轴，这也是为什么同一把武器在不同构筑下表现差异极大。

## 四、武器系统

### 4.1 一条武器的全部数值维度

| 维度 | 含义 |
|---|---|
| **Base Damage** | 单次命中的基础伤害（受 Might 乘区） |
| **Area** | 攻击范围基础值（受 Area 乘区） |
| **Speed** | 投射物速度基础值（受 Speed 乘区） |
| **Duration** | 效果持续时间（受 Duration 乘区） |
| **Amount** | 每次发射的投射物数量（受 Amount 加算） |
| **Cooldown** | 冷却时间（受 Cooldown 乘区；**部分武器从 Duration 结束后才开始转**） |
| **Interval** | 多发投射物之间的间隔（如 Fire Wand 0.02s） |
| **Pierce** | 可穿透的敌人数 |
| **Knockback** | 击退强度 |
| **Pool Limit** | 场上同时存在的投射物上限 |
| **Hitbox Delay** | 同一敌人被同一投射物再次命中的最短间隔（所有延迟会**同时重置**，导致实际命中率高于理论值） |
| **Chance** | 特殊效果触发概率（受 Luck） |
| **Crit Multi** | 暴击伤害倍率 |
| **Block by Walls** | 是否被障碍物阻挡 |

### 4.2 本体武器总表（攻击类）

"忽略"列指该武器**不吃**哪些属性乘区——这是构筑时最容易踩的坑。

| 武器 | 基础伤害 | 满级 | 稀有度 | 初始持有者 | 解锁条件 | 进化 |
|---|---|---|---|---|---|---|
| **Whip** 鞭子 | 10 | 8 | 100 | Antonio | 默认 | Bloody Tear |
| **Magic Wand** 魔杖 | 10 | 8 | 100 | Imelda | 默认 | Holy Wand |

## 五、进化系统

### 5.1 三种"进化"形态

| 形态 | 定义 | 结果 |
|---|---|---|
| **Evolution（进化）** | 满级基础武器 + 对应被动 + **宝箱** | 基础武器被替换为进化武器，被动保留 |
| **Union（合成）** | 两把（或更多）**都满级**的武器 +（可能需要的）被动 | 多把武器合并成一把，**腾出武器槽** |
| **Gift（赠礼）** | 满足条件后额外获得 | 不替换任何东西，相当于白送一件 |
| **Morph（变形）** | 特定角色升到 80 级 + 对应 Chaos 遗物 | 角色变形，初始武器同时进化，**不需要宝箱** |

### 5.2 进化的硬性规则

1. 基础武器必须**满级**。
2. 对应被动必须**已获得**；其中一部分要求被动**也满级**（银戒/金戒/左右 Metaglio、以及后续更新加入的多数武器）。
3. 必须开一个**"含进化"的宝箱**：通常是 **10:00 之后**的 Boss 掉落，部分地图/Boss 例外（Dairy Plant、Cappella Magna、Il Molise、Boss Rash 等所有宝箱都能进化；Mad Forest 1:00 的第一只发光蝙蝠宝箱也能）。
4. 一次宝箱通常只能进化**一把**武器（部分高级宝箱可进化 2–5 把）。
5. **进化会移除基础武器**（Union 会移除全部素材武器）——基础武器的所有效果消失，进化武器冷却从 0 开始。
6. **进化武器没有常规等级**：它是固定数值的一件成品，入手即为其唯一等级（只有 Limit Break 能让它继续成长，且进化时额外属性会被重置）。**唯一例外是合成武器 Vandalier**——它有 8 个等级。
7. **拿到 Yellow Sign 之后，所有"能够进化"的宝箱都会显示为银色**，方便辨认。
8. 宝箱的第一个奖励位会被进化占用，其余奖励照常。

## 六、数值联动与构筑

### 6.1 三条成长轴的关系

```
武器强度 = 基础伤害 × Might × (等级加成) × 触发频率(1/Cooldown)
有效输出 = 武器强度 × 命中数（靠 Area / Amount / Pierce / 弹速）
生存能力 = Max Health + Armor + Recovery + Revival + 无敌时间
```

**结论**：`Amount` 与 `Area` 属于"乘在命中数上"的属性，在怪群密集的后期收益远高于单纯堆 Might；而 `Cooldown` 是被严重低估的属性（Empty Tome 满级 −40%，等于输出 ×1.67）。

### 6.2 被动与武器的配对逻辑

被动有两类用途，**不要混用**：

| 类型 | 例子 | 用途 |
|---|---|---|
| **纯数值型** | Spinach、Candelabrador、Bracer、Spellbinder、Empty Tome、Duplicator | 直接提升所有武器，优先堆 |
| **纯进化型** | Armor、Wings、Stone Mask、Skull O'Maniac、Pummarola | 本身对输出几乎无用，只为解锁进化而带 |

实战建议（来自 Wiki 的通用策略）：**至少 4 个被动位留给纯数值型**；进化型被动等构筑方向确定后再补。

### 6.3 几个反直觉的数值事实

- **King Bible 的 Cooldown 从 Duration 结束才开始算**，所以它的实际冷却 = 3s + Duration。堆 Duration 会同时延长持续与冷却。
- **Hitbox Delay 同时重置**：多个圣经/投射物共享延迟，任一到期会重置全部计数，导致实际命中频率高于理论。
- **Area 对 King Bible 可能是负收益**：范围越大圈越大，敌人反而更容易从缝隙挤进来。
- **Garlic 降低敌人击退抗性**，与 King Bible 组合可以形成"敌人根本走不到你面前"的封锁。
- **Amount 对 Carréllo 不加投射物，而是加弹跳次数**。
- **Pentagram 只吃 Cooldown 与 Luck**，堆 Might 完全无效。

## 七、常见误解

1. **"6 个武器 6 个被动就是全部"** —— 错。舞台道具、金宝箱、暗宝箱、Arma Dio 都能突破上限。
2. **"进化后还能升级"** —— 错。进化武器是固定数值成品；只有 Limit Break 能继续成长，且进化时额外属性清零。
3. **"宝箱奖励是随机的，运气好就给进化"** —— 只有**含进化能力的宝箱**（通常 10:00 后）才会把第一个奖励位换成进化，且要求你已满足条件。
4. **"属性对所有武器都有效"** —— 错，见 §4.3，很多武器完全忽略某些属性。
5. **"Curse 是纯负面"** —— 它同时提高敌人数量与刷新频率，等于提高经验与金币产出，是后期刷取构筑的核心。
6. **"被动只有 21 件"** —— 旧统计；当前本体 23 件（19 普通 + 4 特殊）。
